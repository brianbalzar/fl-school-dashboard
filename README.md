# Florida District Facilities

Energy, operations & maintenance, capacity and five-year capital plan benchmarks for Florida's 67 school districts, built from public FLDOE, NCES and U.S. Census data.

The page is encrypted (AES-256-GCM, PBKDF2-SHA256 key derivation) and opens with an access key. Deep link to a district with `#District`, e.g. `#Marion` or `#Palm_Beach`.

Built and published from the `florida-schools` working folder with `scripts/build_dashboard.py` and `scripts/build_locked.py`.
